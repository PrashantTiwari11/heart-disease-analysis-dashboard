# ❤️ Heart Disease Analysis Dashboard (Microsoft Excel)

## 📌 Project Overview

The **Heart Disease Analysis Dashboard** is an interactive Microsoft Excel project designed to analyze patient health records and identify trends related to heart disease. The dashboard provides meaningful insights through KPIs, Pivot Tables, Pivot Charts, and Slicers, helping users explore patient demographics and health conditions efficiently.

## 🎯 Project Objectives

- Analyze heart disease prevalence among patients.
- Compare disease distribution across different age groups.
- Study gender-wise heart disease trends.
- Analyze blood pressure categories.
- Identify chest pain type distribution.
- Analyze exercise-induced angina.
- Build an interactive Excel dashboard for healthcare insights.
